# Бот-аналитик ресторанных новостей

Каждое утро (08:00 Ташкент) собирает новости про выбранные компании, ИИ (Gemini, бесплатно) отбирает важное
(лояльность, акции, цены, конфликты, точки, кадры) и присылает короткий отчёт в Telegram и/или на почту.

## Что понадобится
1. Бесплатный ключ Gemini: https://aistudio.google.com -> Get API key. Это GEMINI_API_KEY.
   (Без ключа бот работает в упрощённом режиме по ключевым словам.)
2. Telegram-бот: напишите @BotFather -> /newbot -> получите TELEGRAM_BOT_TOKEN.
   Затем напишите своему боту любое сообщение и откройте
   https://api.telegram.org/bot<ТОКЕН>/getUpdates, там найдите "chat":{"id":...} — это TELEGRAM_CHAT_ID.
3. (по желанию) почта: SMTP_HOST (например smtp.gmail.com), SMTP_USER, SMTP_PASS (пароль приложения), EMAIL_TO.
4. Аккаунт GitHub (бесплатно).

## Запуск автоматически (бесплатно, через GitHub Actions)
1. Создайте приватный репозиторий и загрузите туда все файлы этой папки (включая .github).
2. Settings -> Secrets and variables -> Actions -> New repository secret. Добавьте:
   GEMINI_API_KEY, TELEGRAM_BOT_TOKEN, TELEGRAM_CHAT_ID (и SMTP_*/EMAIL_TO, если нужна почта).
3. Вкладка Actions -> "Daily restaurant news" -> Run workflow. Это ручной тест.
4. Дальше бот сам запускается каждый день.

## Проверка на компьютере
    pip install -r requirements.txt
    export GEMINI_API_KEY=...   # и остальные переменные
    python main.py

## Настройка
Все компании, запросы и Telegram-каналы лежат в config.yaml.
Чем больше полезных Telegram-каналов вы добавите, тем лучше отчёт: Google News ловит не всё.

## Ограничения
- Instagram и закрытые каналы бот не читает.
- Если новостей нет, придёт короткое «ничего важного».
- ИИ пересказывает только то, что есть в тексте, но спорные новости проверяйте по ссылке.
- Лимиты бесплатного тарифа Gemini и название модели Google иногда меняет. Если пришла ошибка, бот сам переключится на ключевые слова, а модель можно поменять в config.yaml.
